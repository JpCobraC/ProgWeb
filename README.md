# EcoField - Monitoramento de Campo 🌿

Aplicativo mobile desenvolvido em React Native com Expo Router, aplicando Clean Architecture (Arquitetura Limpa).

## Funcionalidades

- 🔐 **Autenticação**: Tela de login.
- 📸 **Captura de Câmera & GPS**: Registro de foto acompanhada da localização atual do dispositivo.
- 📋 **Lista de Observações**: Visualização de registros salvos localmente no dispositivo.
- 🗺️ **Mapa Interativo**: Exibição de pins com janela detalhada (foto e localização) das observações registradas.
- 🧪 **Testes Unitários**: Testes automatizados para regras do domínio com Jest.

## Tecnologias Utilizadas

- **Expo / React Native** (Expo Router, Expo Camera, Expo Location)
- **React Native Maps**
- **Async Storage** (`@react-native-async-storage/async-storage`)
- **Jest & Testing Library**
